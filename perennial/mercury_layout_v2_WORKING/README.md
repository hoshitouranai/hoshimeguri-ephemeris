# 水星詳細の2027年採用表示統合（WORKING）

元の正式LOCKED ZIPは無変更。作業用派生版。
`python build_year.py --year 2028 --months all` で年間・月間・水星CSVに加え、2027年版と同構成の2列表＋下段年間参考情報を生成します。
水星PNG名 `{year}_水星の運行詳細_2027年版統一.png`。元の5列WORKING PNGも内部参考として残しますが、正式表示ではありません。
2028/2029年の出力・SHA256確認後に採用を判定。
注記: 24件超の年は自動レイアウト拡張未対応のため明示エラーとなります。したがって現時点では全ての年への適用を無検証で保証しません。
