## 検査範囲と残る制約
- 外部資料照合は上記**抜き取り**であり、全イベント・全日全天体の独立再計算を意味しない。
- 確認した年度は2028/2029。1900〜2099を引数で受け付ける設計だが、全年度の実行検証を行ったわけではない。
- Fontは同梱していない。Python環境依存（numpy,scipy,matplotlib,pyswisseph,Pillow,PyMuPDF,Noto CJK/FreeSerif）。
- 年間図・月間図・水星図・表紙の図面デザインは2027年販売PDFと完全同一とは限らない。販売用PDF作成はこのLOCKEDの対象外。
- 図の最終的な編集長による個別目視承認は、今回の会話での『はい』による作業続行の範囲と区別する。図面の全要素の個別承認を受けたとは記載しない。
- PDF表紙が作られる場合があるが、主要LOCKED対象は年指定生成コード・図PNG・イベントCSV。
